# Ender Obelisks

![Карта обелисков](https://github.com/stardely62-oss/modhyed/releases/download/dev/screenshot.png)

Fabric-мод для **Minecraft 1.20.1** от euf. Добавляет эндер-обелиски: ставишь их по миру и прыгаешь между ними через карту.

## Обелиск

- Высота 2 блока. Обсидиановый постамент со сланцевыми угловыми камнями, колонна из тёсаного тёмного камня с алмазными поясами, сверху клетка из полированного глубинного сланца с алмазным кольцом и алмазным шпилем.
- В клетке парит **око эндера** и **следит за ближайшим игроком**. Когда рядом никого нет, оно медленно вращается.
- Вокруг клетки затягиваются светлые руны стола зачарований. Ночью око и орнамент светятся.
- Каждый уровень улучшения зажигает на колонне ещё одно кольцо бирюзового орнамента (цепочка ромбов).
- **Крафт:** эндер-жемчуг сверху; в среднем ряду полированный глубинный сланец, алмаз, полированный глубинный сланец; внизу 3 обсидиана.
- Ломать может только владелец (или оператор). Взрывы обелиск не берут, добывается алмазной киркой.

## Телепортация

- ПКМ по обелиску открывает меню. Слева **карта**: вид сверху на места, где ты уже бывал, все доступные обелиски с названиями, круг дальности и твоя позиция. Колесо мыши масштабирует, перетаскивание двигает, клик выбирает.
- Справа: название (можно переименовать), доступ, улучшение, выбранная цель с расстоянием и кнопка «Телепортироваться», а ниже список обелисков по расстоянию.
- Прыжок бесплатный. После него 30 секунд перезарядки. Прыгать можно только внутри одного измерения.
- **Дальность** считается от обелиска, *с которого* прыгаешь:

| Уровень | Дальность | Цена улучшения |
|---|---|---|
| 0 | 500 | — |
| 1 | 1000 | золотой блок + 4 эндер-жемчуга |
| 2 | 2000 | 4 алмаза + 8 эндер-жемчугов |
| 3 | 3500 | 8 эхо-осколков |
| 4 | 5000 | звезда Незера |

- **Доступ:** владелец переключает «для всех» / «только я». Чужие личные обелиски на карте не видны, и прыгать к ним нельзя.
- Название по умолчанию можно задать, переименовав предмет на наковальне.

## Установка (TLauncher)

1. В TLauncher выбери версию **Fabric 1.20.1** и запусти её один раз до главного меню, потом закрой.
2. Открой [последнюю сборку](https://github.com/stardely62-oss/modhyed/releases/tag/dev) и скачай `ender-obelisks-updater.zip`.
3. Распакуй архив и запусти **`update-ender-obelisks.bat`**.
4. Скрипт сам:
   - найдёт папку `mods`;
   - поставит подходящий под твой Fabric Loader Fabric API;
   - скачает мод, а старую версию и тестовый мод Modhyed удалит.

Чтобы обновиться, запусти скрипт ещё раз. С ключом `-Stable` он поставит последний стабильный релиз вместо dev-сборки.

## Разработка

- Код пишет агент (Claude Code + [Universal Modder](https://github.com/rehan-remade/universal-modder)). Сборка и проверка идут только в GitHub Actions ([workflow](.github/workflows/build.yml)):
  1. `./gradlew build`
  2. `./gradlew runGametest`: [GameTest-ы](src/gametest/java/euf/enderobelisks/test/ObeliskGameTests.java) на headless-сервере проверяют размещение, реестр, разрушение, уровни, телепорт, перезарядку и права.
  3. `scripts/ci-harness.sh`: настоящий клиент под Xvfb на сгенерированном мире ([сценарий](src/gametest/java/euf/enderobelisks/test/HarnessClient.java)). Ставит обелиск кликом, открывает меню, прыгает, проверяет дальность, перезарядку и права, улучшает и снимает скриншоты.
  4. При зелёном `main` обновляется релиз [`dev`](https://github.com/stardely62-oss/modhyed/releases/tag/dev). Тег `v*` выпускает стабильный релиз.
- Модели генерирует [`tools/gen_models.py`](tools/gen_models.py), текстуры [`tools/gen_textures.py`](tools/gen_textures.py).
